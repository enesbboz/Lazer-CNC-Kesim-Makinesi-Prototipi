# Lazer-CNC-Kesim-Makinesi-Prototipi
Temel Özellikler:

Manuel Kontrol: Kullanıcının eksenleri anlık olarak yönlendirerek, çalışma alanı içindeki istenilen bölgede serbest işlem yapmasına olanak tanır.

Otonom Mod (Öğretilmiş Rota): Sisteme önceden öğretilmiş kesim koordinatları ve rotalar, makine tarafından insan müdahalesi olmadan otomatik olarak takip edilir ve işlenir.

Güvenli Donanım Simülasyonu: Gerçek lazer modülleri yerine bobinler kullanılarak güvenli bir test ortamı ve elektronik yük simülasyonu oluşturulmuştur.
